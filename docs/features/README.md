---

## Guidelines for Feature Specifications
1. Every new feature must be documented using the standardized 18-point template: [`_template.md`](./_template.md).
2. Features must specify user problems, scope boundaries, data models, and acceptance criteria before implementation begins.
3. Clearly label implementation status (`Planned`, `In Development`, `Implemented`, `Verified`).
